# 契約書メーカー

いつも使っている **Word の契約書をそのままひな形にして**、必要な情報を入力するだけで契約書を完成させる Web アプリです。
インストール不要で、ブラウザだけで動きます（Chrome / Edge 推奨）。

## いちばん大事な方針：元の Word の書式には一切手を加えない

社内規定で書式が厳しく決まっている契約書でも使えるよう、次のように作っています。

| 項目 | どうなるか |
| --- | --- |
| フォント・文字サイズ・太字・下線 | **変わりません**。差し込んだ文字は「その場所にもともとあった文字」の書式をそのまま使います |
| 改行・段落・行間・字下げ | **変わりません**。段落の追加・削除はしません（複数行の入力欄に自分で改行を入れた場合のみ、その位置に改行が入ります） |
| スペース・空白 | **変わりません**。差し込み箇所の前後の全角スペースなどもそのまま残ります |
| 表・罫線・余白・ヘッダー/フッター・画像・ロゴ | **変わりません**。差し込みのない部品は、元ファイルのデータをそのままコピーします |
| 本文の文言 | **変わりません**。変わるのは `{{項目名}}` の部分だけです |

さらに、Word 出力のたびに「差し込み箇所以外の文字が 1 文字でも変わっていないか」を自動で検証し、万一違いがあれば出力を中止します。

> 画面右側のプレビューは確認用の簡易表示です（フォントの有無などで見た目が少し異なることがあります）。
> 出力される Word ファイルは、元ファイルの書式のままです。
> PDF が必要な場合は、出力した Word を開いて「名前を付けて保存 → PDF」で保存してください（Word 上の見た目のまま PDF になります）。

## 使い方

### 1. ひな形を登録する（最初の1回だけ）

1. `index.html` をブラウザで開く
2. 左下の「**＋ Wordからひな形を作る**」で、いつもの契約書（.docx）を選ぶ
   - `.doc`（古い形式）の場合は、Word で「.docx」形式で保存し直してください
3. 文書が表示されるので、毎回変わる文字（お客様名・金額・日付など）を**ドラッグで選択**し、「この文字を入力項目にする」を押す
4. 項目名を選ぶ（「注文者（施主）氏名」「請負代金額」などの候補から選べます）
   - 同じ文字が文書内のほかの場所にもあれば、まとめて置き換えられます
   - 間違えたら「↶ 元に戻す」、または右側の項目の「解除」で元の文字に戻せます
5. 右側で、項目の種類（日付・金額など）や、未入力のときに入れる文字などを設定して「保存」

Word 上であらかじめ `{{注文者_氏名}}` のように書いておいた箇所も、自動で入力項目になります。

### 2. 契約書を作る（毎回）

1. 左の一覧からひな形を選ぶ
2. フォームに入力（Enter キーで次の項目へ）。入力した内容はプレビューにすぐ反映されます
3. 右上の「**Word出力**」を押す

- 一度入力したお客様情報・工事情報は、**ほかの書類（約款・合意書など）に切り替えても自動で入ります**（項目名が同じもの）。
- 自社名・所在地・許可番号など「記憶」の項目は、次の案件でも自動で入ります。
- 別のお客様の契約書を作るときは「新しい案件」を押します。過去の内容は「履歴」から呼び出せます。

## 入力項目の設定

| 設定 | 内容 |
| --- | --- |
| 種類 | テキスト / 複数行 / 日付（和暦・西暦を切り替え）/ 金額（3桁カンマ）/ 数値 / 選択肢 |
| 数字を全角にする | 日付・金額・数値を全角で差し込みます（例：令和８年１０月１日、３３，０００，０００）。規定に合わせて選んでください |
| 未入力のときに入れる文字 | 空欄のまま / 全角スペース（手書き用の余白）/「―」など、規定に合わせて設定できます |
| 入力を記憶 | 自社情報など、毎回同じ内容の項目に |
| 必須 | 未入力のまま出力しようとすると確認が出ます |

差し込まれる文字は、入力欄の下に「差し込まれる文字：令和8年11月1日」のように表示されます。

## ひな形の共有

- **1つのひな形を渡す**：エディタの「ファイルに書き出す」で `.json` を作り、受け取った人は「ひな形ファイルを読み込む」で取り込みます。
- **全員に配る（配布ひな形）**：エディタの「配布用に書き出す」で `.js` を作り、`templates/` に置いて `index.html` の末尾に `<script src="templates/ファイル名.js"></script>` を1行追加します。

画面から作ったひな形は、そのパソコンのブラウザに保存されます。ほかのパソコンでも使う場合は上のどちらかの方法で共有してください。

## 社内への公開（GitHub Pages）

1. GitHub のリポジトリで **Settings → Pages** を開く
2. Source を「Deploy from a branch」、Branch を公開したいブランチ・`/ (root)` にして保存
3. 数分後に表示される URL を社内で共有する

共有フォルダに置いて `index.html` を開く運用でも使えます。入力した情報はブラウザの中だけに保存され、外部には送信されません。

## 注意

- 同梱の「サンプル：工事請負契約書」は動作確認用です。自社の Word から作ったひな形に差し替えてください。
- 選択した文字が途中で書式の違う部分をまたぐ場合（例：名前の一部だけ太字）、差し込んだ文字は選択範囲の**先頭の文字の書式**になります。
- 差し込む文字が元の文字より長い・短い場合、その分だけ後ろの文字の位置は動きます（Word で手入力した場合と同じです）。

## ファイル構成

```
index.html              画面
css/style.css           デザイン
js/app.js               フォーム・プレビュー・ひな形エディタ・履歴
js/docx-template.js     Word ひな形エンジン（差し込み箇所の文字だけを書き換える）
js/zip.js               .docx(ZIP) の読み書き（変更しない部品はそのままコピー）
js/presets.js           建築工事請負向けのよく使う項目名
templates/*.js          配布ひな形
```
