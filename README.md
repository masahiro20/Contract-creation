# 契約書メーカー

ひな形を選んで必要な情報を入力するだけで契約書が完成する Web アプリです。
インストール不要で、ブラウザだけで動きます。

- **入力 → 即プレビュー**：入力した内容がリアルタイムで契約書に反映されます。未入力の箇所は黄色で表示され、クリックするとその入力欄に移動します。
- **出力**：Word（.docx）、印刷 / PDF、テキストコピー
- **自社情報の記憶**：「記憶」マークの項目（自社名・住所・代表者など）は次回から自動で入ります。
- **下書きの自動保存と作成履歴**：途中で閉じても入力内容は残ります。過去に作った契約書の内容を呼び出して、少しだけ変えて作り直すこともできます。
- **和暦 / 西暦の切り替え**、金額のカンマ区切り、条番号（第1条・第2条…）の自動採番
- **オプション条項の ON/OFF**：「再委託を認める」などのスイッチで条文を切り替えられます。
- **ひな形はあとから自由に追加**：アプリの画面から追加でき、プログラムの知識は必要ありません。

> 入力した情報はブラウザの中だけに保存され、外部のサーバーには送信されません。

## 使い方

1. `index.html` をダブルクリックしてブラウザ（Chrome / Edge 推奨）で開く
   - または GitHub Pages で公開した URL を開く（下記）
2. 左の一覧からひな形を選ぶ
3. フォームに入力する（Enter キーで次の項目へ移動できます）
4. 右上の「Word出力」または「印刷 / PDF」を押す
   - PDF にするには、印刷画面で送信先に「PDF に保存」を選択します

## ひな形の追加方法

### 方法A：アプリの画面から追加する（おすすめ）

1. 左下の「＋ 新しいひな形」を押す
2. 今使っている Word の契約書の本文をコピーして、本文欄に貼り付ける
3. 毎回変わる部分（相手の会社名、金額、日付など）を選択して「選択した文字を入力項目にする」を押し、項目名を付ける
   - 同じ文言がほかにもあれば、まとめて置き換えられます
4. 右側で各項目の種類（日付・金額・選択肢など）や「記憶」の設定をして「保存」

作ったひな形は「マイひな形」に入ります。ほかの人と共有するときは、エディタの「ファイルに書き出す」で `.json` を作って渡し、受け取った人は「ひな形ファイルを読み込む」で取り込みます。

### 方法B：標準ひな形としてファイルで追加する（全員に配る場合）

1. `templates/` に `.js` ファイルを追加する（`templates/gyomu-itaku.js` をコピーして書き換えるのが簡単です）
2. `index.html` の末尾に `<script src="templates/ファイル名.js"></script>` を1行追加する

### 本文の書き方

| 書き方 | 意味 |
| --- | --- |
| `{{乙_名称}}` | 入力項目。同じ名前はすべて同じ値が入ります |
| `{{契約日:date}}` | 種類を指定（`date` 日付 / `money` 金額 / `textarea` 複数行 / `number` 数値 / `select` 選択肢） |
| `# タイトル` | 中央・大きい文字のタイトル |
| `## 第{{条}}条（目的）` | 太字の見出し。`{{条}}` は条番号を自動で振ります |
| `> 甲　住所…` | 右寄りに字下げ（署名欄） |
| `>> 文字` | 右寄せ |
| `{{#if 自動更新}}…{{else}}…{{/if}}` | ON/OFF で文章を出し分け（`{{#unless …}}` は OFF のとき表示） |
| `===` | 改ページ |

ファイルで書く場合の項目設定（`fields`）の例：

```js
{ key: '甲_名称', label: '会社名', group: '甲（自社）', remember: true },
{ key: '委託料', label: '委託料（税抜）', type: 'money', group: '委託料' },
{ key: '支払期日', label: '支払期日', type: 'select', options: ['翌月末日', '翌月20日'] },
{ key: '契約締結日', label: '契約締結日', type: 'date', default: 'today' },
{ key: '乙_代表者', label: '代表者', required: false, hint: '個人の場合は空欄' },
```

`fields` に書かなかった `{{…}}` も自動で入力欄になります。

## 社内への公開（GitHub Pages）

1. GitHub のリポジトリで **Settings → Pages** を開く
2. Source を「Deploy from a branch」、Branch を公開したいブランチ・`/ (root)` にして保存
3. 数分後に表示される URL を社内で共有する

サーバーや月額費用は不要です。共有フォルダに置いて `index.html` を開く運用でも使えます。

## 注意

同梱の3つのひな形（業務委託・NDA・物品売買）は一般的な条項のサンプルです。実際の運用では、自社で使っている契約書のひな形に差し替えてください。

## ファイル構成

```
index.html          画面
css/style.css       デザイン・印刷レイアウト
js/app.js           差し込み処理・フォーム・ひな形エディタ
js/docx.js          Word(.docx) 生成（外部ライブラリなし）
templates/*.js      標準ひな形
```
